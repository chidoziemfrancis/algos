# Object-Oriented Programming (OOP) Fundamentals

## 1. Constructors
* **Meaning:** Special methods used to initialize objects when an instance of a class is created.
* **Project:** User Profile System

## 2. Encapsulation
* **Meaning:** Bundling of data and methods that operate on that data into a single unit, restricting direct access to some components.
* **Project:** Bank Account Manager

## 3. Abstraction
* **Meaning:** Hiding complex implementation details and showing only the necessary features of an object.
* **Project:** Smart Home Controller

## 4. Inheritance
* **Meaning:** A class (subclass) acquiring the properties and behaviors of another class (superclass).
* **Project:** Vehicle Fleet Management

## 5. Polymorphism
* **Meaning:** Objects of different types being treated as objects of a common base type, often through method overriding or overloading.
* **Project:** Universal Media Player
